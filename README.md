## Descripción

Repositorio para almacenar las prácticas del curso de Aplicaciones Web.

## Práctica Laravel (CRUD HTTP)

- **Ubicación:** `/practica-Laravel`
- **Tecnologías:** Laravel 12, Blade, Bootstrap 5, Vite.
- **Instrucciones de ejecución:**
  1. `cd practica-Laravel`
  2. `composer install`
  3. `npm install`
  4. `cp .env.example .env` (o copiar y pegar el archivo manualmente)
  5. `php artisan key:generate`
  6. `php artisan serve` (en una terminal)
  7. `npm run dev` (en otra terminal)
